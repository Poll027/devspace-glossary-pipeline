FACT f1 IF(logical_test, value_if_true, value_if_false) returns one of two results according to the test.
FACT f2 Use =IF(test1, result1, IF(test2, result2, result3)) to express three ordered alternatives.
FACT f3 IFS(test1, result1, test2, result2, ...) returns the result for the first true condition.
FACT f4 A final TRUE condition in IFS supplies a default result; without a true condition, IFS returns #N/A.
tb1 Suppose a spreadsheet labels order amounts using a hypothetical policy: amounts above 100 are High, amounts above 50 but not above 100 are Medium, and the rest are Low. A2 contains the amount to classify.
tb2 IF(logical_test, value_if_true, value_if_false) returns one of two results according to the test.
tb3 Use =IF(test1, result1, IF(test2, result2, result3)) to express three ordered alternatives. IFS(test1, result1, test2, result2, ...) returns the result for the first true condition. A final TRUE condition in IFS supplies a default result; without a true condition, IFS returns #N/A.
tb4 For a two-way decision, =IF(A2>100,"High","Other") returns High when the test is true and Other when it is false. For three ordered alternatives, use =IF(A2>100,"High",IF(A2>50,"Medium","Low")). The second test is reached only through the false alternative of the first.

The same policy can be written =IFS(A2>100,"High",A2>50,"Medium",TRUE,"Low"). IFS returns the result associated with the first true condition; the final TRUE supplies a default. With amounts 120, 75, and 40, the results are High, Medium, and Low. Exactly 100 is Medium and exactly 50 is Low because these tests use >, not an inclusive comparison.

If the IFS expression contains only the two amount tests and neither is true, it returns #N/A. The final TRUE avoids that no-true-condition case by providing the default. The useful skill is tracing ordered tests rather than assuming the formula evaluates all matching labels and combines them.
tb5 In IFS, the first true condition wins. Putting A2>50 before A2>100 would classify 120 as Medium in this policy. A final TRUE supplies a default; without any true condition, IFS returns #N/A rather than an invented blank or Low label.
