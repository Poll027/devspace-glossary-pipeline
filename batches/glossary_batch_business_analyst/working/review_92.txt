tb4 In report view, select fields from the Data pane and a visual type from Visualizations to add a visual to the canvas. For this hypothetical page, use Branch and Amount for the requested comparison. Arrange the most important information prominently and keep the page focused on that audience question.

Choose comparisons or trends appropriate to the need, avoid clutter, and use consistent display choices. A second visual should have a clear role in answering the question instead of being added only because another chart is available. The example does not prescribe a universal number of visuals.

The useful output here is a focused report page, not a service dashboard created by renaming the canvas. The business question guides field choice and arrangement, while the tool actions explain how a beginner places a visual.
tb5 A Power BI report page and a service dashboard are distinct. Selecting visuals on the report canvas does not by itself create a dashboard collection of tiles. Also, more visuals do not automatically improve the answer; keep the page focused and consistent.
