tb1 Imagine a Tableau dashboard for comparing order amounts across branches. First build a worksheet view suitable for that comparison. Drag the category dimension Branch to Rows and numeric measure Amount to Columns, or reverse those placements, and use Bar as the mark type. These placements create the category/value bar view for the example.
tb2 A Tableau dashboard combines views from worksheets in one place.
tb3 Build a worksheet bar chart by dragging a category dimension to Rows and a numeric measure to Columns (or vice versa), using Bar as the mark type; these field placements create the category/value view that can be placed on the dashboard. Select New Dashboard and drag sheets from the dashboard pane onto the canvas. Choose a dashboard size suited to how the audience will view it, and arrange the most important view prominently. Limit the number of views to keep the dashboard focused and readable.
tb4 Select New Dashboard and drag the worksheet from the dashboard pane onto the canvas. A Tableau dashboard combines worksheet views in one place; it is not the same artifact as a single worksheet. Choose a dashboard size suited to how the audience will view it, then arrange the most important view prominently.

Limit the views so the dashboard remains focused and readable. If another worksheet adds a useful perspective, give it a clear role. Do not add every worksheet simply because it exists. The particular layout and size are decisions for the audience, not mandatory measurements in this concept.

The useful output is a dashboard built from appropriate worksheet views, with the core comparison visible. The workflow makes both stages explicit: create the category/value worksheet and then place it on the dashboard. A beginner should not be expected to already know how the first chart comes into existence.
tb5 A dashboard combines worksheet views; creating a worksheet is not the same as creating the dashboard. Conversely, opening New Dashboard does not create a category/value chart until an appropriate worksheet view is available and placed there.
