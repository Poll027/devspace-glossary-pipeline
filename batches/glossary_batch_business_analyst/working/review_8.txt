tb1 Imagine the team has agreed on the problem “Dispatch staff cannot find current delivery instructions.” The brainstorming goal is to generate alternative ideas for addressing that problem, not to decide immediately which idea wins.
tb2 Brainstorming generates alternative ideas for a shared problem.
tb3 State the session’s problem and goal, set a time limit, choose a facilitator, and record contributed ideas. Keep idea generation separate from judging ideas so participants can explore possibilities.
tb4 State the problem and goal to the participants. For this hypothetical session, choose a facilitator, set a fifteen-minute limit, and prepare a place to record ideas. Contributors suggest a single instruction summary, a clearer amendment label, or a revised handoff between sales and dispatch. Record those contributed ideas so the discussion does not depend on remembering who said what.

Keep generation separate from judgment. If a participant responds to the first suggestion with “That will never work,” the facilitator can return the session to generating alternatives and leave evaluation for a separate discussion. This does not mean every idea must later be selected. It means the current activity is exploration, so an idea is recorded before it is judged.

At the end, the result is a set of alternatives connected to the same shared problem. The example ideas are possibilities, not recommended solutions. The distinction matters for a BA: a session aimed at generating ideas should not be described as if it had already established requirements or chosen an implementation. The facilitator, limit, and record provide a concrete frame for that exploration.
tb5 Separating generation from judgment is not the same as promising to implement every suggestion. Brainstorming produces alternatives for a shared problem. A session that immediately debates each contribution is mixing the two activities rather than preserving the stated separation.
