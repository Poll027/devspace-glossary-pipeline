FACT f4 Use =SUM(range) to total values, =AVERAGE(range) for their arithmetic mean, and =COUNT(range) to count numeric cells.

Copy a formula containing relative and fixed references and inspect how each reference changes according to the destination. AVERAGE ignores empty cells and text in a referenced range but includes cells containing zero.
tb4 A relative reference such as A1 changes with the copied position. $A$1 fixes both row and column; $A1 fixes only the column, and A$1 fixes only the row. For example, copying a formula from C2 to D3 shifts a relative A1 to B2, keeps $A$1 unchanged, shifts $A1 to $A2, and shifts A$1 to B$1. Inspect the destination formula instead of assuming every reference moves identically.

For the sample amounts, =SUM(A2:A4) returns 30, =AVERAGE(A2:A4) returns 10, and =COUNT(A2:A4) returns 3 because all three cells are numeric. AVERAGE includes zero. If A4 were empty rather than zero, the average of the referenced numbers would be 15, not 10; text and empty cells are ignored in that range calculation.

The practical skill is reading both the calculation and the reference behavior. Fixed references preserve an intended shared input while relative references move to the corresponding source cell when copied.
tb5 A dollar sign fixes the part it precedes, not always the whole reference. Also, zero and an empty cell do not have the same effect on AVERAGE: zero is included, while empty cells and text in the referenced range are ignored.
