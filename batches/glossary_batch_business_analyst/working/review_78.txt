FACT f1 A lookup retrieves a value associated with a matching key.
FACT f2 Use =XLOOKUP(key, lookup_range, return_range) to find a key and return the corresponding value; exact match is the default.
FACT f3 Use =VLOOKUP(key, table_range, column_number, FALSE) for an exact match in the first column and a return value from the specified column to its right.
FACT f4 If VLOOKUP’s final argument is omitted or TRUE, it uses approximate matching and expects the first column sorted.
FACT f5 Use =INDEX(return_range, MATCH(key, lookup_range, 0)) to return the value at the exact key’s position.
tb1 Imagine a customer list with identifiers 101 and 102 in A2:A3 and names North Stores and South Stores in B2:B3. D2 contains the identifier 102. A lookup retrieves the value associated with a matching key.
tb2 A lookup retrieves a value associated with a matching key.
tb3 Use =XLOOKUP(key, lookup_range, return_range) to find a key and return the corresponding value; exact match is the default. Use =VLOOKUP(key, table_range, column_number, FALSE) for an exact match in the first column and a return value from the specified column to its right. If VLOOKUP’s final argument is omitted or TRUE, it uses approximate matching and expects the first column sorted. Use =INDEX(return_range, MATCH(key, lookup_range, 0)) to return the value at the exact key’s position.
tb4 Write =XLOOKUP(D2,A2:A3,B2:B3) to return South Stores. Exact match is the default. With the same two-column list, =VLOOKUP(D2,A2:B3,2,FALSE) also returns South Stores: it finds an exact key in the first column and returns column 2 to its right.

Do not omit FALSE casually in this exact-key example. If VLOOKUP’s final argument is omitted or TRUE, it uses approximate matching and expects the first column sorted. That is a different lookup mode, not merely shorter spelling for the exact request.

Another exact form is =INDEX(B2:B3,MATCH(D2,A2:A3,0)). MATCH with 0 finds the exact key’s position, and INDEX returns the value at that position from the return range. In the sample, the key is second and the returned name is South Stores.

The useful BA task is joining a needed business label to a known key through the lookup ranges. Keep the ranges aligned in the example so the matching position corresponds to the intended returned value.
tb5 VLOOKUP’s omitted final argument is not exact matching. For the supported exact pattern, use FALSE; approximate matching expects a sorted first column. XLOOKUP’s exact default and MATCH’s 0 also need to be read as part of the chosen lookup form.
