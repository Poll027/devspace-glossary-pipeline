FACT f1 A PivotTable is a tool to calculate, summarize, and analyze data that lets you see comparisons, patterns, and trends in your data.
FACT f2 To create a PivotTable, select the data cells, select Insert > PivotTable, choose where to place the PivotTable report, and select OK.
FACT f3 To add a field to the PivotTable, select its checkbox in the PivotTable Fields pane; selected fields are added to their default areas, with non-numeric fields added to Rows and numeric fields added to Values, and a field can be moved to a different area by dragging it there.
FACT f4 Filters area fields are shown as top-level report filters above the PivotTable; Columns area fields are shown as Column Labels at the top of the PivotTable; Rows area fields are shown as Row Labels on the left side of the PivotTable; Values area fields are shown as summarized numeric values in the PivotTable.
tb1 Suppose a worksheet has columns Branch and Amount, with North amounts 40 and 60 and South amount 30. A PivotTable can calculate, summarize, and analyze those rows to reveal comparisons rather than displaying only the original records.
tb2 A PivotTable is a tool to calculate, summarize, and analyze data that lets you see comparisons, patterns, and trends in your data.
tb3 To create a PivotTable, select the data cells, select Insert > PivotTable, choose where to place the PivotTable report, and select OK. To add a field to the PivotTable, select its checkbox in the PivotTable Fields pane; selected fields are added to their default areas, with non-numeric fields added to Rows and numeric fields added to Values, and a field can be moved to a different area by dragging it there. Filters area fields are shown as top-level report filters above the PivotTable; Columns area fields are shown as Column Labels at the top of the PivotTable; Rows area fields are shown as Row Labels on the left side of the PivotTable; Values area fields are shown as summarized numeric values in the PivotTable.
tb4 Select the source data cells, choose Insert > PivotTable, select where to place the report, and choose OK. In the PivotTable Fields pane, check Branch and Amount. The nonnumeric Branch field is added to Rows by default, and the numeric Amount field to Values. Fields can be moved by dragging them to the desired area.

Read the areas deliberately. Rows creates row labels on the left, Columns creates column labels at the top, Values displays summarized numeric values, and Filters provides report filters above the PivotTable. In this hypothetical report, using Branch in Rows and Amount summarized by a total in Values gives North 100 and South 30. That illustrates the intended summary; inspect the numeric summary rather than assuming every possible source field produces the same calculation.

The useful output is a summarized view built from field placement. Moving a field changes its role in the report, so explain the placement in business terms: Branch defines the comparison groups and Amount provides the numeric summary.
tb5 Checking a field uses its default placement; that placement is not a permanent rule. Drag fields to the area serving the question. Rows, Columns, Filters, and Values are different roles, and a numeric summary should not be mistaken for an original record.
