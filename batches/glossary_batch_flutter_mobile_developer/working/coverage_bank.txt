@0 flutter_docs#tools/hot-reload:How-to-perform-a-hot-reload
Run a supplied project with `flutter run` on a physical or virtual target in debug mode to use hot reload.
After modifying a Dart source file, enter `r` in the running terminal or use the editor's hot-reload control and check the running app for the change.
Hot reload preserves application state, whereas hot restart restarts the Flutter app and loses that state.
A source change becomes visible only if the changed code executes again; use restart when the change requires application initialization to run again.
@1 dart_language#variables
