What is a Release Plan?
Definition: A release plan is a tactical document designed to capture and track the features planned for an upcoming release. A release plan usually spans only a few months and is typically an internal working document for product and development teams. Release plans can be created using a number of solutions such as roadmapping software or a business model canvas.
