w configuration and credentials command examples Supported config file settings Configuration and credential file settings in the AWS CLI You can save your frequently used configuration settings and credentials in files that are maintained by the AWS CLI. The files are divided into profiles . By default, the AWS CLI uses the settings found in the profile named default . To use alternate settings, you can create and reference additional profiles. You can override an individual setting by either setting one of the supported environment variables, or by using a command line parameter. The AWS CLI stores sensitive credential information that you specify with aws configure in a local file named credentials , in a folder named .aws in your home directory.
