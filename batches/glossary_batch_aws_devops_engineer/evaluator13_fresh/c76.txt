
### 76 security.audit_storage_encryption
Inline: KMS key-use authorization for SSE-KMS only, not SSE-S3: SSE-KMS reads require both S3 object access and permission to use the KMS key; SSE-S3 does not require KMS key-use authority. This local encryption model is taught here.; SSE-KMS key-use authority locally taught (not required for SSE-S3): This concept teaches that SSE-KMS requires S3 object authorization and KMS key-use authority. SSE-S3 does not require KMS key-use authority.
tb1: An audit reader can address an S3 object but still lacks the required KMS authority. Separate object access, key authority and the individual object's encryption metadata before interpreting the read result.
tb2: SSE-KMS encrypts S3 objects with an AWS KMS key, while SSE-S3 uses S3-managed keys.
tb3: Reading an SSE-KMS object requires both s3:GetObject permission and kms:Decrypt authority for its key; SSE-S3 does not require KMS key-use permission.

Configure the supplied KMS key as bucket default encryption and test reads with approved object/key authority and with KMS use denied; inspect the object’s encryption metadata.
tb4: Configure the supplied KMS key as the bucket's default encryption. For the supplied SSE-KMS object, test a read under approved s3:GetObject and kms:Decrypt authority. Then run the case where KMS use is denied and inspect the result. Read the object's encryption metadata to confirm what applies to that object. Changing bucket default encryption does not re-encrypt existing objects, so a default setting alone is not proof of an older object's encryption. Compare this with the stated SSE-S3 boundary: S3-managed-key encryption does not require KMS key-use permission. Keep those two encryption models distinct in the evidence instead of adding a KMS requirement to every S3 read.
tb5: Bucket default encryption does not change the individual encryption of objects that already exist. Inspect object metadata. Also, SSE-KMS read access needs both object permission and KMS Decrypt authority; SSE-S3 does not require KMS key-use permission.
