A preview describes proposed changes without performing them, so retain execution evidence separately from the review. Even a preview that matches the requested scope does not guarantee execution will succeed.

A reviewer should be able to distinguish three records: the template and scope requested, the change-set actions previewed, and the later execution outcome. If the preview does not match the requested scope, execution should not be described as the approved change. If the preview matches but execution fails, preserve the failed outcome; the successful preview is not contradictory evidence because it was never a guarantee of execution success.
tb5: Creating a change set does not provision its resources. It previews changes without executing them. Likewise, a clean review is not a guarantee of execution success; inspect the preview before authorization and distinguish it from the later execution outcome.
