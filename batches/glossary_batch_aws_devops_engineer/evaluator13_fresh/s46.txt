Managing instance profiles (console) If you use the AWS Management Console to create a role for Amazon EC2, the console automatical nsole does not create an instance profile for a role that is not associated with Amazon EC2. You can use the AWS Management Console to delete IAM roles and instance profiles for Amazon EC2 if the role and the instance profile have the same name. To learn more about deleting instance profiles, see Delete roles or instance profiles . Note To update permissions for an instance, replace its instance profile.
