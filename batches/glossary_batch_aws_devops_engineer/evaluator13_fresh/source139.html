Get secrets from AWS Secrets Manager

Secrets Manager generates a CloudTrail log entry when you retrieve a secret. For more information, see Log AWS Secrets Manager events with AWS CloudTrail.

You can retrieve secret values using:

  • Java

  • Python

  • .NET

  • Go

  • Rust

  • Amazon EKS

  • AWS Lambda

  • AWS Workload Credentials Provider

  • AI Coding Agents

  • C++

  • JavaScript

  • Kotlin

  • PHP

  • Ruby

  • AWS CLI

  • AWS console

  • AWS Batch

  • CloudFormation

  • GitHub jobs

  • GitLab

  • AWS IoT Greengrass

  • Parameter Store
