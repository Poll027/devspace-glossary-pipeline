
### 80 aws.credential_expiry

### 81 aws.ecs_task_identity
INLINE supplied ECS task=supplied; task role versus execution role=The task role authorizes application AWS calls; the execution role authorizes ECS startup work such as image pulls and log setup.; supplied task=supplied
f1 The ECS task role supplies credentials for AWS calls made by the application containers.
f2 The task execution role authorizes ECS startup work such as pulling an image and publishing logs; it is distinct from application AWS permissions.
f3 Set taskRoleArn to the approved least-privilege application role in the task definition and test allowed and denied application operations from the task.
tb1 An ECS task starts, yet its application still needs AWS permissions. Separate the task execution role's startup work from the task role used by application containers.
tb4 In the supplied task definition, set taskRoleArn to the approved least-privilege application role. From the task, test the supplied allowed and denied application operations. Inspect those results under the task's application identity. The execution role covers startup work such as image pulling and log publication; those capabilities do not substitute for the application role's permissions.
tb5 The task execution role is not the task role. Successful image pulling or log publication does not establish application AWS access. Set and test the approved taskRoleArn for application calls.
