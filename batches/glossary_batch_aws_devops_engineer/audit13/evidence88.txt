Each resource instance independently determines whether it needs to be refreshed, so refreshing one resource does not cause other resources that depend on it to be refreshed.
50: -replace=ADDRESS - Instructs Terraform to plan to replace the resource instance with the given address. Terraform will use a "replace" action if the specified resource would normally cause an "update" action or no action at all. Include this option multiple times to replace several objects at once. You cannot use -replace with the -destroy option, and it is only available from Terraform v0.15.2 onwards. For earlier versions, use terraform taint to achieve a similar result.
